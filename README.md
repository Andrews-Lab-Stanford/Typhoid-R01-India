# Typhoid-R01-India

This repository includes scripts to replicate the Stanford/CMC/MGH/UC Davis analyses of typhoid surveillance in Vellore, India.

## Directory Structure

- **0-project-functions**: Internal functions used in analysis (e.g., diagnostic tools).
- **1-data-cleaning**: Scripts to prepare and clean REDCap data for analysis.
- **2-analysis**: Core analysis and visualization scripts (e.g., SAP analysis, spatial correlations, and models).
- **3-tables**: Scripts specifically designed to produce summary and result tables.
- **data**: Datasets and associated libraries required for the analyses.
- **figures**: Folder containing figure outputs (plots, maps, and flowcharts) generated by the scripts.
- **results**: Output files from analyses that do not contain any patient identifiers.
